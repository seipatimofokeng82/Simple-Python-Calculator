# Simple-Python-Calculator
A Python calculator demonstrating basic arithmetic operations, input validation, exception handling, and interactive menus.

This project is a simple command-line calculator built with Python. It allows users to perform basic arithmetic operations while demonstrating input validation and exception handling.

Features

Addition, subtraction, multiplication, and division.
Interactive menu for selecting operations.
Accepts two numbers from the user.
Validates user input to ensure valid numeric values.
Handles invalid inputs using ValueError.
Prevents division by zero using ZeroDivisionError.
Uses try, except, else, and finally for exception handling.
Allows users to perform multiple calculations or exit the program.
Displays a message indicating whether the operation succeeded or failed.
